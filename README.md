## 🔎 Sobre

Este repositório centraliza tudo que produzo na área de **computação em nuvem**: laboratórios práticos, anotações, projetos e material de estudo.

> 💡 **Repositório em construção.** Atualmente o conteúdo disponível é focado na preparação para a **WorldSkills Cloud Computing** — novos labs e projetos serão adicionados com o tempo.

---

## 📁 Estrutura do Repositório

```bash
cloud-computing/
├── docs/                   # Anotações e referências de serviços (em breve)
├── iam/                    # Configurações de Identidade e Acesso
│   ├── policies/           # Políticas de permissão (ex: oidc-access-policy.json)
│   └── trust-policies/     # Políticas de relação de confiança (ex: oidc-trust-policy.json)
├── labs/                   # Labs práticos de cloud (em breve)
├── worldskills/            # Preparação para a WorldSkills: cenários, scripts e templates
└── README.md

---

## 🌩️ WorldSkills

A pasta [`worldskills/`](./worldskills) concentra todo o material de treino para a competição:

- **Cenários simulados** com empresas fictícias
- **Diagramas de arquitetura**
- **Scripts de automação** (User Data, Bash, AWS CLI)

Para detalhes completos, consulte o [README da pasta worldskills](./worldskills).
